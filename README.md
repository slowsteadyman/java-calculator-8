# java-calculator: 문자열 계산기

---
숫자와 구분자로 구성된 문자열을 입력하면 숫자들의 합을 출력하는 프로그램입니다.   
(ex. '1,2,3' => 6)

---
## ✅ 구현한 기능 
- 문자열 입력 받기
- 잘못된 입력에 대한 예외 처리
- 커스텀 구분자 확인하기
- 구분자를 통한 문자열 분리
- 분리된 문자열을 더해주기
- 더한 결과를 출력하기

---
## ➕ 사용 방법

- 기본 입력 양식: 숫자 사이에 구분자를 포함해서 입력
  - 허용되는 구분자는 ' __:__ ', ' __,__ '
  - __입력 예시: '1,2:3'__
- 커스텀 구분자 입력: 입력할 문자열 앞에 __'//커스텀구분자\n'__ 입력
  - 구분자는 한 글자여야 한다.
  - 숫자가 아닌 구분자는 모두 사용 가능하다.
  - __입력 예시 1: '//;\n1,2;3'__
  - __입력 예시 2: '//\\\n1\233,444\5'__
- 앞뒤나 사이의 공백이나 문자는 허용하지 않는다.
  - __잘못된 입력 예시1: ' 1, 2, 3'__
  - __잘못된 입력 예시2: 'a//;\n   1;  2, 3.'__
